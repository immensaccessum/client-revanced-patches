# Client Patches

Custom bytecode patches designed for local use with [ReVanced Manager](https://github.com/ReVanced/revanced-manager).

> [!IMPORTANT]
> **No Application Binaries Distributed**: This repository contains strictly bytecode transformation instructions. It does NOT host, bundle, or distribute any proprietary applications, APKs, or copyrighted binaries. All patching is performed entirely locally on your personal device.

---

## Installation

1. Install [ReVanced Manager](https://github.com/ReVanced/revanced-manager/releases/latest).
2. Go to **Settings** → **Sources** (or tap the gear icon next to Patches source).
3. Set the patch source URL to:
   ```
   https://github.com/immensaccessum/client-revanced-patches/releases/latest/download/patches.json
   ```
4. Select the target application, choose desired patches, tap **Patch**, and install.
   *(Note: The patched app has a different signature. The original application must be uninstalled first. Back up any local app data beforehand).*
