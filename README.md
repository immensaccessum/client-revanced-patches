# Patches

Патчи для ReVanced Manager. В репозитории только патч. Файл приложения сюда не входит: его берёт Manager с телефона.

## Установка

1. Поставить [ReVanced Manager](https://github.com/ReVanced/revanced-manager/releases/latest).
2. Patches → карандаш → плюс → Enter URL:

   `https://github.com/immensaccessum/client-revanced-patches/releases/latest/download/patches.json`

3. Apps → установленное приложение → Patch → Install.

Поверх версии из магазина не встанет: подпись другая. Прежнее приложение сначала снимается. Локальные данные при удалении пропадают, если их заранее не выгрузил из самого приложения.
