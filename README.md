# Патчи клиента 4PDA

Патчи для официального приложения `ru.fourpda.client`. В репозитории только патч. Apk клиента здесь нет: его берёт ReVanced Manager с телефона.

## Сейчас

**Show status immediately.** Нижняя строка («Загрузка темы…») появляется сразу. В клиенте 1.9.44 перед показом стоит пауза 3000 мс; патч меняет её на 0. Когда ответ сервера уже пришёл, клиент строку по-прежнему убирает. На быстрой связи она мелькнёт. Смотреть лучше страницу, которая грузится дольше секунды.

Сверено по разборке 1.9.44. На другой сборке патч встанет, только если в `MainLayout` остались те же `3000` и `postDelayed`.

## Телефон

1. Поставить [ReVanced Manager](https://github.com/ReVanced/revanced-manager/releases/latest).
2. Patches → карандаш → плюс → Enter URL:

   `https://github.com/immensaccessum/4pda-revanced-patches/releases/latest/download/patches.json`

3. Apps → установленный 4PDA → Patch → Install.

Поверх магазинной версии не встанет: подпись другая. Официальный клиент сначала снимается. Вход и локальные закладки при удалении пропадают, если их заранее не выгрузил из самого клиента.
