# 4PDA ReVanced Patches

Custom patch bundle for the 4PDA Android client, designed for local use with [ReVanced Manager](https://github.com/ReVanced/revanced-manager).

> [!IMPORTANT]
> **No APKs Distributed**: This repository contains only bytecode transformation instructions (patches). It does NOT host, contain, or distribute any proprietary applications, APKs, or copyrighted assets. All patching takes place locally on your personal device.

---

## Installation

1. Install [ReVanced Manager](https://github.com/ReVanced/revanced-manager/releases/latest).
2. Go to **Settings** → **Sources** (or tap the gear icon next to Patches source).
3. Set the patch source URL to:
   ```
   https://github.com/immensaccessum/client-revanced-patches/releases/latest/download/patches.json
   ```
4. In ReVanced Manager, select the installed 4PDA app (`1.9.44_pre7`), choose your desired patches, tap **Patch**, and install.
   *(Note: The patched app has a different signature, so uninstall the stock version beforehand. Back up any local app data first).*
